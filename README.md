<h1 align="center">国际中文教学辅助AI语伴助手</h1>
面向留学生课后缺乏沉浸式口语练习场景、通用大模型回答易脱离教学大纲的问题，构建软硬协同的 AI 语伴终端并完成模型私有化部署：基于 Docker + vLLM 本地化部署 Qwen3:32B、Qwen2.5:32B 等 10 款开源模型，采用 INT8 量化将单卡显存占用由 34 GB 压至 28 GB，端到端响应速度提升约 2.5 s。
硬件以 ESP32-S3 为核心构建低功耗终端，负责语音采集、控制逻辑执行与实时字幕输出，通过精简电路与智能休眠策略保障弱网、偏远环境下长期稳定运行，并采用模块化架构封装语音、图像、显示组件，支持即插即用与动态升级。软件侧的关键决策有三：一是模型层放弃云端 API 改为本地部署，原因是教学语料与学习数据不出校内网且长期使用成本可控，服务端基于 Anaconda 搭建 Python 环境统一调度各 AI 模块；二是多模态能力，搭建 Fun-ASR 语音识别、GLM-4V 视觉大模型与 CosyVoice 语音克隆服务端并封装统一接口，集成流式 ASR、流式 TTS 与 VAD 语音活动检测，支持多语言处理；三是接入与检索，依托 Dify 构建 RAG 流程，支持教材 PDF 与文本语料上传、向量化与语义检索，终端与服务端通过 WebSocket 保持长连接，借助 FRP 内网穿透实现远程调用与联调。
